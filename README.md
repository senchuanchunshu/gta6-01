Cinder Bay — an original sun-soaked open-world crime game, built for make.fun's "Make GTA 6" bounty. Explore a coastal city on foot and by car, steal cars, outrun the Cinder Bay PD through a 5-star wanted system, and run five story jobs for Rocco Marlowe's crew. Traffic, pedestrians, combat, a HUD with a live minimap, synthesized sound, and saving — all in plain static files, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move/drive, E to enter a car, mouse + click to fight, Q to switch weapon, P to pause.
